## 登录与账号

首次访问 `http://127.0.0.1:8000` 会进入登录页。

- **开发模式**（默认 `WANREN_AUTH_MODE=dev`）：内置账号 `admin@wanren.local` / `wanren-dev-admin`
- **注册**：登录页「注册」标签页可创建账号（角色由 `WANREN_REGISTRATION_ROLE` 决定，默认 EDITOR；生产模式默认关闭注册）
- **修改密码 / 管理成员**：ADMIN 角色在「用户」页操作

五种角色的权限边界：

| 角色 | 能做什么 |
|---|---|
| EDITOR 编辑 | 创建对话、上传素材、生成与改稿 |
| REVIEWER 审核 | 编辑权限 + 预审 / 人工通过 / 驳回 |
| PUBLISHER 发布 | 编辑权限 + 同步草稿 / 定时发布 / 发布 |
| VIEWER 只读 | 只能查看 |
| ADMIN 管理员 | 全部权限 + 用户 / 公众号管理 |

## 界面总览

- **顶栏**：工作台 / 流程 / 任务 / 文章 / 素材 / 公众号 / 样式 / 监控 / 用户 / 设置；右侧全局搜索（对话 / 文章 / 素材）与主题切换（6 套配色，本地记忆）
- **左侧对话树**：按「公众号 → 对话」分组，点击任意对话即进入该文章的编辑视图；悬停出现删除（二次确认）；「已发布」可折叠隐藏
- **侧栏宽度**可拖动分隔条调整，双击恢复默认；顶栏最左按钮可整体收起侧栏
- **中间区**：文章编辑器（与公众号 677px 同宽）；**右侧**：对话改稿面板，宽度同样可拖动

## 第一次创作：从想法到草稿

### 1. 新对话

点左上「＋ 新对话」，在居中弹窗里：

1. **写需求**：描述想写的文章（例：「把这份论文写成一篇公众号深读，面向非专业读者」）
2. **拖素材**：PDF / 图片 / Word / Excel / 文本 / MP4 直接拖入或粘贴，随首条消息一起发送
3. **选样式**：一行样式胶囊里点选排版气质（眼睛图标可先看整篇排版样例）
4. **选公众号**：决定发到哪个账号
5. 点「开始对话」

### 2. 架构提案（AI 先想清楚再动笔）

AI 会阅读你上传的全部素材，然后给出**提案卡**：

- **拟题**与一句话定位
- **逐节大纲**：每节标题 + 这节要写什么
- **推荐样式**与推荐理由（附备选，可就地换）

你可以：

- **✓ 确认开始写作** —— 按大纲生成全文
- **直接回复修改意见** —— 例如「扩成 6 节」「第 3 节改成方法对比」，AI 重新提案
- **取消对话** / **中途终止**（思考中可点「终止」按钮，两步确认防误触）

> 未确认提案前不能生成正文——这是刻意的流程设计：返工成本前置为零。

### 3. 生成与进入编辑

确认后 AI 开始写作（生成中有骨架屏动画，可中途终止）。完成后自动进入核心工作形态：**中间编辑 + 右侧对话**。左侧对话树会即时出现这条新对话。

## 编辑器详解

编辑区固定 **677px 宽**（与公众号发布正文一致），样式模版的字体、颜色、章节徽章、论文配图、指标数据卡全部实时呈现——**中间看到什么，发布后就是什么**。

- **直接编辑**：标题、摘要、章节标题、正文段落都可点击直接改，改动即时标脏
- **保存**：`Ctrl+S` 或工具栏「⇧ 保存」，每轮保存生成一个版本（历史全保留）
- **沉浸模式**：点右上「沉浸」收起其余面板，专心改稿；工具栏出现完整排版控件
- **等比缩放**：鼠标放在中间区或右侧对话区，`Ctrl + 滚轮` 整体等比放大/缩小（70%–200%），排版宽度不变、字重不糊——预览放大不改变任何发布效果
- **排版工具栏**：对齐 / 段前 / 段后 / 首行缩进 / 行距 / 字距，作用于当前小节；这些参数在发布时转为内联 CSS **原样带到公众号**
- **段落 / 章节管理**：`＋段落`、`－当前段`、`＋章节`、`－章节`；每个章节至少保留一个段落
- **论文配图**：从 PDF 抽取的插图自动编号（图注「论文图 N（第 M 页）」），与发布版一致
- **指标数据卡**：AI 从素材中提炼的关键数字（如百分比、规模）自动渲染为两列数据卡，位置与发布版完全一致

## 对话式改稿

右侧面板像和编辑聊天一样连续改稿：

- **快捷指令**：「精简短读」「加强解释」等一键填入
- **AI 工具循环**：AI 会先 `read_article` 读当前稿，再 `insert_blocks` / `replace_blocks` 逐块修改——每一步都显示在对话流里，正文里对应段落以黄色高亮 + 动画出现，你能**看着它写**
- **高亮回放**：点历史工具消息可回放当时的改动；版本消息的「高亮本版改动」重现整轮 diff
- **中途终止**：思考中或执行中都可点「■ 终止」（两步确认），立即停下且不留半成品
- **每轮可回退**：不满意点「↩ 回退」恢复到任意历史版本，回退本身也可再回退
- **拖素材进对话**：拖图片/文件到右侧面板即可随消息发送；图片自动可用于封面与视觉分析

## 样式模版系统

「样式」页是样式画廊：每张卡片是**无文字的迷你版式示意**，点开可看整篇排版样例（观点文 / 数据解读 / 步骤教程 / 清单体四种示例任选）。

| 内置样式 | 气质 | 适合 |
|---|---|---|
| 蓝调杂志 | 深蓝刊头、栏目感 | 深度阅读、品牌栏目 |
| 暗夜科技 | 深底高对比 | 科技、AI、数码 |
| 极简黑白 | 无色、留白 | 长文、随笔 |
| 暖纸阅读 | 米色纸感 | 人文、故事 |
| 清新治愈 | 浅绿柔和 | 生活、健康 |
| 商务蓝灰 | 稳重分区 | 报告、行业 |
| 活力橙黄 | 高亮强调 | 活动、营销 |
| 学术线框 | 线框 + STEP 徽章 | 论文解读、教程 |

- **切换样式**：编辑器工具栏的「样式」下拉随时换，全文版式即时变化（只换样式，不动内容）
- **复制到公众号**：样例预览里「⧉ 复制到公众号」复制富文本，可直接粘进公众号编辑器
- **导入自定义样式**：「⇩ 导入样式」粘贴样式令牌 JSON（先用「⇪ 导出」拿一份现成的改最稳）。令牌关键字段：

| 字段 | 含义 | 取值示例 |
|---|---|---|
| `accent` | 主色（必填） | `#14532D` |
| `text` / `title` / `muted` | 正文/标题/辅助色 | 十六进制色值 |
| `font` | 字体 | `songti` / `fangsong` / `heiti` / `kai` |
| `radius` | 圆角 | `0`–`12` |
| `header` | 刊头样式 | `magazine` / `dark_banner` / `center` / `frame` |
| `section_heading` | 章节标题样式 | `dot` / `step` / `navy_bar` / `thin_line` 等 |
| `quote` | 引用样式 | `soft_card` / `accent_card` / `definition` 等 |
| `end` | 文末收束 | `references` / `tip` / `cta` / `dots` 等 |

浅底色、边框色、辅助色留空会由主色自动派生。

## 素材库

「素材」页按「公众号 → 对话」两级折叠分组，每个对话的素材相互独立。

- **支持类型**：TXT / MD / CSV / JSON / XLSX / PDF / DOCX / PNG / JPG / WebP / MP4
- **PDF 自动抽图**：上传论文 PDF 时自动抽取内嵌大图（≥400×200）作为「论文图 N」派生素材，生成时插入对应章节
- **视觉分析**：图片可选多模态大模型理解或 VidLens 本地脚本分析，结果折叠展示
- **视频**：MP4 自动抽取首帧作为封面候选，并可转码为公众号友好的 720p/360p 版本

## 文章审核与状态流转

```
生成 → AI_REVIEWED（待人工） → HUMAN_APPROVED（已通过） → WECHAT_DRAFT → PUBLISHED
                ↘ NEEDS_REVISION（待修订，继续对话改稿）
                ↘ REJECTED（驳回）
```

- **AI 规则预审**：每次生成/修订自动跑一遍（分数环 + 问题清单），可「↻ 重新预审」
- **人工终审**：REVIEWER/PUBLISHER 点「✓ 人工通过」或「× 驳回」；人工通过是发布的前置条件
- **原创声明**：需要原创声明的文章，先「▶ 同步草稿」，到公众号编辑器开启原创声明并保存，回万仞点「确认原创声明」解锁发布
- **版本历史**：每轮 AI 修订/手动编辑都存版本，随时回退

## 同步草稿与发布

前提：`WANREN_PUBLISHER=wechat` 且账号已通过「检测连接」（见 README 第三步）。

1. **封面**：微信草稿必须带封面图——在对话中上传任意图片即可（最新图片自动作为封面候选）
2. **▶ 同步草稿**：把当前文章（含全部排版样式）推送到公众号草稿箱；再次同步会 `draft/update` 更新**同一条草稿**，不会越堆越多
3. **⟳ 校验微信草稿**：拉取草稿最新状态（是否被人在后台改过/删除）
4. **⏱ 定时发布**：选时间与时区（支持「今晚 20:00 / 明早 08:00」快捷），到点自动发布；可改期/取消
5. **⇥ 发布**：直接发布。个人主体公众号遇到 `48001` 属正常（无发布 API 权限），请用草稿 + 后台手动发布
6. 发布后文章卡片显示「查看文章」链接；发布状态回调可自动回传（可选配置，见 README）

## 导入微信草稿

不是在万仞写的稿子也能接进来：侧栏「⇩ 导入」→ 选公众号 → 列出草稿箱 → 选一条导入为对话。AI 解析其结构后即可继续用对话改稿，再同步回**同一条**草稿。

## 监控 / 用户 / 设置

- **监控**：健康度、队列与运行任务（点开看节点轨迹）、操作审计分页
- **用户**：成员管理（角色、最近登录）
- **设置**：
  - **视觉分析**：多模态大模型（推荐）或 VidLens 本地脚本（完全离线）
  - **主文本模型**：OpenAI 兼容三件套（地址只填根地址），密钥加密存储、只显脱敏形式；「◎ 检测连接」一键验证
  - **计费**：可配置模型单价与月度预算，工作台「AI Tokens / 成本」卡片实时累计
- **流程**：查看当前任务的 8 阶段流程与所处节点

## 常见问题

README 的 FAQ 表覆盖发布类问题（40164 IP 白名单 / 48001 / 封面图 / mock 模式 / 模型连接），另补充：

| 现象 | 解决 |
|---|---|
| 点对话树没反应 / 显示旧文章 | 刷新页面（Ctrl+F5）；对话树与编辑区由同一状态驱动，异常时刷新即恢复 |
| 生成中想停下 | 思考卡或对话面板的「终止」按钮（两步确认） |
| 编辑区内容不见了 | 检查是否仍在沉浸模式；「退出沉浸」恢复三栏 |
| 上传 PDF 报「创建失败：surrogates not allowed」 | 旧版本缺陷，已修复；更新到最新版 |
| 对话改稿没有逐块高亮 | 主模型是本地适配器时自动降级为整篇修订；接入远端模型恢复 |
| 想换界面配色 | 顶栏右侧色点切换（墨青/黛蓝/石墨/朱砂/紫棠/潮汐），设置页也可切 |

## 数据与备份

- 所有数据在 Docker 卷 `wanren-data`（SQLite）与 `wanren-storage`（素材文件）里
- 备份/迁移：停机后整卷打包（命令见 README「停止 / 升级 / 备份」）
- 删除对话会级联删除其素材、文章与版本历史（不可恢复，删除有二次确认）
